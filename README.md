# harv-themes

Custom themes for [harv](https://github.com/iskaa02/rawi). Each folder is one theme (`theme.toml` + optional `style.css`).

## Install

One command — clone this repo as your themes folder:

```sh
git clone https://github.com/iskaa02/harv-themes ~/.config/harv/themes
```

If you already have a `~/.config/harv/themes` folder, add the themes to it instead:

```sh
curl -sL https://github.com/iskaa02/harv-themes/archive/refs/heads/main.tar.gz | tar -xz --strip-components=1 -C ~/.config/harv/themes
```

Then pick one in Preferences → Appearance → Style. Update later with `git -C ~/.config/harv/themes pull`.
